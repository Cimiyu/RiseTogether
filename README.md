# 🌍 RiseTogether

RiseTogether is a modern social networking platform designed to help people connect, learn, collaborate, and grow together.

The platform allows users to:

- Create accounts
- Share posts
- Upload images
- Comment and like posts
- Follow other users
- Send messages
- Join communities
- Attend live meetings
- Learn through AI-powered assistance

# Backend Setup

```bash
cd backend

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

uvicorn app.main:app --reload
```
